# Академия ДПК — готовые тесты

В комплекте:
- День 1 — 15 вопросов;
- День 2 — 20 вопросов;
- Итоговая аттестация — 25 вопросов;
- одиночный и множественный выбор;
- проверка ответов на сервере;
- проходной балл 80%;
- отправка результата и ошибок в Discord через webhook;
- поля Имя Фамилия, Static ID, Discord ID.

## Установка на Vercel
1. Импортируйте этот репозиторий в Vercel.
2. В Vercel: Settings → Environment Variables.
3. Создайте переменную `DISCORD_WEBHOOK_URL` и вставьте webhook нужного Discord-канала.
4. Deploy.

Webhook Discord: Настройки текстового канала → Интеграции → Вебхуки → Новый вебхук → Копировать URL.

Рекомендуемый канал: `📊・результаты-тестов` (закрыт для стажёров).

Юридические вопросы собраны по предоставленной памятке: УПК ст. 28, 44, 48, 49, 51, 53, 54; ФЗ «Об ОРД» ст. 6.1 и 7.1; ст. 9 закона о режимных/государственных территориях; КоАП ст. 15.2 ч. 3; алгоритм адвоката и сроки 60/90 минут.
